# KickUp
📖 Description

A fullstack web application composed of a frontend and an Express backend API, designed to manage students in a martial arts school.

The system allows instructors and administrators to handle student profiles, track class attendance, and manage progression through belt/grade levels.

Built with a scalable and decoupled architecture, separating the user interface from the business logic.

🚀 Features
👤 Student profile management
📅 Attendance tracking
🥋 Belt/grade progression system
🏫 Class and schedule organization
🔗 REST API with Express
🎯 Goal

To simplify and digitalize the daily management of a martial arts school while serving as a solid fullstack project foundation.
